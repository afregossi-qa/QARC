# QARC — POS Reference Implementation

This folder shows how QARC is configured for a POS product domain.
It is a structural reference — the actual content files (product.md, tech.md)
contain company-specific information and are not committed.

## What to do

1. Read the onboarding guide: `ONBOARDING.md`
2. Fill in `.kiro/steering/product.md` with your product context
3. Fill in `.kiro/steering/tech.md` with your tech stack
4. Run your first ticket following `ONBOARDING.md`
